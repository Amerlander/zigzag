# ZigZag 0.1.7

Chats with the agent kept with each design, images and slash commands in
the prompt, and a design review before sewing; Blend, which sews across
gaps where the thread won't show instead of cutting; threads routed by
hand; files opened in the window that's already running; and fixes for
designs and tools that could crash the app.

## Working with an agent

- Each design keeps its chats with the agent, on this computer and never
  in the file: a design's last chat comes back when it's opened, and
  `/history` opens an earlier one. Up to 20 chats are kept per design.
- Paste an image (⌘V) or drop one on the Agent panel to send it with the
  prompt. It shows as a thumbnail until it's sent, then in the chat, and
  the agent can trace it.
- Type `/` in the prompt for commands: `/model` and `/effort` choose the
  model and how hard it thinks, `/agent` switches between Codex and Claude
  Code, `/new` starts a new chat, `/history`, `/stop`, `/fix` (asks the
  agent to fix the design's problems) and `/help`.
- When there's a real choice to make, the agent offers it as a card in
  the chat: each option with what it gains and what it costs, ticked and
  applied by you.

## Agents

- `review_design` reviews the whole design as an embroiderer would before
  it's sewn: what it costs to sew (threads, thread changes, trims and the
  objects behind most of them, time) and what may not read clearly
  (pieces under 1.5 mm, gaps sewn across in plain view, threads too close
  to the fabric's color).
- `get_cuts` lists where the thread is cut, with the way round each one
  that shows least; `set_object`'s `route_mm` sews the thread that way
  instead of cutting.
- `align_objects` lines objects up or spaces them evenly, to each other or
  to the hoop; `combine_shapes` unites, subtracts, intersects or excludes
  filled shapes; `rename_object`; `redo`; and `offer_choices` for the cards
  above.
- What an agent made remembers the prompt it was made for, in the file.

## Stitching

- **Blend** in the Document panel (off by default): gaps up to this long
  are sewn across where the thread is close in color to what it crosses
  (the same thread, a lighter or darker one, or cloth of its own color),
  and less far the plainer it would show. The panel says how many cuts it
  saved. It's judged against the cloth color in Preview.
- A thread can be routed by hand to an object from the one sewn before it,
  through points you give (`via=X:Y+X:Y` in a layer name, `via=direct`
  for straight there).

## Opening files

- Opening a file while ZigZag is running hands it to the window that's
  there, as a tab, instead of starting a second window that overwrote the
  first one's session. `--new-window` (or `ZIGZAG_NEW_WINDOW`) opens one
  anyway (Juri Wolf).
- A file opened at launch (command line, Open With) opens in a tab on top
  of the tabs that come back, instead of replacing them.
- On Windows the open tabs, unsaved changes, panels and settings survive a
  quit, crash or reboot: they're kept in `%APPDATA%\ZigZag` (Juri Wolf).

## Fixes

- A tool call from an agent that fails inside ZigZag is answered with an
  error instead of taking the app down, and whatever it changed is rolled
  back (Jeroen).
- A design with impossible coordinates (not a number, infinite, or far
  past any hoop) no longer hangs or crashes the machine-file writers or
  draws a stitch through the hoop's center (Jeroen).
- Studio panels, the canvas layout and the Issues list are refined.
