# ZigZag (fork)

This repository is a fork: `origin` is Amerlander/zigzag, `upstream` is simpsoka/zigzag.

## Working on a card

- Before starting, fetch `origin` and `upstream` and check whether the change has already landed there (for example in a merged pull request). If it has, build on that instead of doing it again.
- Once the work has landed on `main`, propose a follow-up card "PR im Upstream" for simpsoka/zigzag: a single commit on top of `upstream/main`, without the Obeya files (`.obeya/` and this `CLAUDE.md`).
